Before you start

You'll need three things in place before the agent can do its first run:

  1. A Linear workspace with a label named exactly agent — create it in Settings → Labels.
  2. A GitHub repository that ABCA has read/write access to (via a GitHub token in your environment).
  3. A running ABCA instance — clone this repo, fill in the .env with your Linear and GitHub tokens, then start the server.

💡 New here? Read the README for a full setup walkthrough.

How it works

01

Label an issue

Add the agent label to any Linear issue. That's the only signal the agent needs — no prompting required.

02

Agent picks it up

Within seconds a background agent receives the webhook, reads the issue title and description, then explores your codebase to understand the context.

03

PR opens

A pull request is opened with a full diff, build & lint results, and plain-English notes explaining every decision — ready for your one-click review.

04

Merge to deploy

Approve and merge the PR. GitHub Actions runs automatically and the live site is updated within ~30 seconds. Done.

Common questions

What does ABCA stand for?

Autonomous Background Coding Agent — an AI agent that runs in the background, picks up coding tasks from Linear, and ships pull requests without any human prompting.

What kind of issues can the agent handle?

Any issue with a clear title and description. The agent works best when you describe the outcome you want (e.g. "Add a FAQ section to the landing page") rather than spelling out exact implementation steps. It figures out the how.

What happens if the build fails?

The agent tries to fix its own errors before opening a PR. If it can't resolve them after several attempts, it opens the PR anyway with a note explaining what failed and why — so you always have full visibility into what happened.

Can I give the agent feedback or ask for changes?

Yes. Update the Linear issue description with new instructions, then remove the agent label and re-add it to trigger a fresh run with the updated context.

Is my code sent to a third party?

The agent reads your repository to understand context and implement changes. Check the README and your ABCA configuration for details on which AI provider is used and how data is handled.
