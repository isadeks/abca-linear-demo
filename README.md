# abca-linear-demo

This repository demonstrates the **ABCA × Linear** integration — an autonomous coding agent that picks up labelled Linear issues and opens pull requests against this repo. The static landing page (see [`index.html`](./index.html)) explains the workflow in plain language. Every pull request merged into `main` is automatically published to **GitHub Pages** via the [`deploy.yml`](./.github/workflows/deploy.yml) workflow, so the live site always reflects the latest state of the `main` branch.
