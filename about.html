ABCA × Linear

About this project

Learn more about the ABCA × Linear Demo and how autonomous coding agents work with your backlog.

ABCA (Autonomous Background Coding Agent) is an AI-powered agent that integrates with Linear to automatically implement issues as pull requests. By labelling a Linear issue with agent, you hand off implementation to the agent — which reads the issue, explores the codebase, makes the necessary code changes, and opens a pull request for your review. The goal is to remove repetitive toil from your workflow so that your team can focus on decisions, not mechanics.
